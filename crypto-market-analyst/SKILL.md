# 加密货币行情解读 · mozi（付费版）

用户问"这币怎么样"时，要的不是价格——免费 App 一秒就能查到。要判断的是：**谁在动它？杠杆挤不挤？现在能不能碰？**

本技能用四层信号回答，免费两层、付费两层：

| 层 | 内容 | 定价 |
|---|---|---|
| 价格结构 | 实时价 + 30 天走势 + 1日/7日/1月/1年区间涨跌 | 免费 |
| 大单主力 | 30 分钟主力净流入、异动评分、Top5 大单明细（mozi 私有侦测引擎，公开 App 拿不到） | **付费** |
| 杠杆温度 | 多空比两档（大户 vs 散户背离）+ 6 所资金费率 | **付费** |
| 情绪极值 | 恐惧贪婪指数 | **付费** |

## 步骤 1 — 解析币种

用户给的符号转大写（btc→BTC）；给了名称则自己映射（ethereum→ETH、solana→SOL、pepe→PEPE）；不确定就问，禁止猜。

## 步骤 2 — 拉取数据（每次提问只跑一次）

```bash
python scripts/fetch_crypto.py <SYMBOL>
```

脚本先发无凭证 probe 请求探测：免费端点直接返回数据；付费端点被服务端以 402 + Payment-Needed 账单门禁。退出码：

| 退出码 | 含义 | 你该做什么 |
|---|---|---|
| 0 | 完整报告 | 直接进入步骤 3 解读 |
| 1 | 符号无效 | 提示用户检查（BTC、ETH、SOL） |
| 2 | 免费段已交付 + 末尾有账单 | 进入下方付费流程 |
| 3 | 支付凭证失效 | 引导重新支付，禁止拿旧凭证重试 |

## 付费流程（支付宝 Machine Pay / 402 按量付费）

这是 AI Agent 间的支付协议：服务端对付费资源下发 402 账单，Agent 支付后携凭证重试解锁。你的职责是让用户无感完成"看到价值 → 付费 → 拿到完整答案"：

1. **先交付再收费**：退出码 2 时，免费段（价格/走势/区间涨跌）已经打印。先把这部分解读给用户，再呈现账单——用户为看得见的价值付费，转化率才高。
2. **账单呈现**：把账单关键项转述给用户：商品（goods_name）、金额（amount）、订单号（out_trade_no）、支付截止（pay_before）。账单有时效，过期作废需重新下单。**禁止在支付完成前编造或预填任何付费段内容。**
3. **携带凭证重试**：用户支付后，平台返回 Payment-Proof 凭证，重跑：
   ```bash
   python scripts/fetch_crypto.py <SYMBOL> --payment-proof "<Payment-Proof>"
   ```
   （或设环境变量 `MOZI_PAYMENT_PROOF`。）凭证经 `Payment-Proof` 请求头送达服务端验付。
4. **验付与履约（服务端侧，你无需操作但需知晓）**：服务端调用 `alipay.aipay.agent.payment.verify` 验付——校验支付 active、金额与账单一致、订单号匹配、资源 ID 匹配，四项全过才放行数据；数据交付后服务端异步调用 `alipay.aipay.agent.fulfillment.confirm` 完成履约确认（complete/ack 回执）。
5. **不重复扣费**：协议保证订单持久化与幂等——out_trade_no 全局唯一、pay_before 过期作废、同一 trade_no 只履约确认一次。网络重试、脚本重跑都不会二次扣费；脚本另有 5 分钟缓存，同期重复查看不再发请求。
6. **凭证失效**（退出码 3）：如实告知凭证已过期/已使用，引导重新支付。

## 步骤 3 — 解读规则（严格）

1. 【最高优先级】只分析用户所问币种，禁止提及其他币种；只使用脚本返回的数据，禁止编造或引用训练知识中的旧价格。
2. 先引用实时价格；缺失时用最近日线收盘价并注明"截至<日期>"。
3. `区间涨跌` 与 24h 涨跌幅口径不同、数值有差异属正常，不是矛盾，无需圆场。
4. **大单主力（付费核心段）**：净流入 >0 主力买方主导、<0 卖方主导；异动评分 total_score ≥70 强异动、40-70 中等；判断持续性要看大单与价格的配合——集中买 + 价升 = 吸货，集中卖 + 价平/跌 = 派发，大单买但价不涨 = 上方抛压重。大单段缺失时明确说"暂无数据"，禁止用其他段补位。
5. 多空比是**账户占比**：>0.5 偏多、<0.5 偏空；top_accounts（大户）与 global_accounts（散户）方向相反是重大信号，必须点出。
6. 资金费率：正 = 多头付空头。**多空比偏多 + 费率高位 = 杠杆拥挤，必须提示连环爆仓（squeeze）风险**；反之亦然。
7. 恐惧贪婪：≤25 极度恐惧 / 25-45 恐惧 / 45-55 中性 / 55-75 贪婪 / ≥75 极度贪婪。仅作情绪背景，不推翻价格结论。
8. 脏数据保护：任何涨跌幅绝对值 >50% 视为坏数据，按缺失处理，绝不复述。
9. 这是加密货币，不提股票概念（ticker、板块、财报、交易时段）。
10. **付费段仍被 🔒 锁定时**：只解读免费段并按付费流程引导解锁；用户已付费后必须交付完整三段——付费用户拿到残缺答案是事故。

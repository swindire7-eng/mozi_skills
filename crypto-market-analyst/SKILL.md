## 步骤 3 — 解读规则（严格）

1. 【最高优先级】只分析用户所问币种，禁止提及其他币种；只使用脚本返回的数据，禁止编造或引用训练知识中的旧价格。
2. 先引用实时价格；缺失时用最近日线收盘价并注明"截至<日期>"。
3. **K线技术面**：MA7>MA30 = 多头排列（短期强于中期），反之空头；30d 区间位置 >80% 接近区间上沿（突破或承压），<20% 接近下沿（超跌或筑底）；连阳/连阴 ≥4 天说明短线动能集中，需提示延续或衰竭；52 周高点/低点距离用来定大周期位置（"距高点 -33%"= 深度回撤位）。K线结论必须与大单段互相印证：价升 + 主力净流入 = 健康上涨，价升 + 主力净流出 = 缩量虚涨要预警。近7日明细中的单日大阳/大阴（|pct|≥5%）是关键事件，应点名日期。
4. `区间涨跌` 与 24h 涨跌幅口径不同、数值有差异属正常，不是矛盾，无需圆场。
5. **大单主力（核心差异段）**：净流入 >0 主力买方主导、<0 卖方主导；异动评分 total_score ≥70 强异动、40-70 中等；判断持续性要看大单与价格的配合——集中买 + 价升 = 吸货，集中卖 + 价平/跌 = 派发，大单买但价不涨 = 上方抛压重。大单段显示"暂无大单数据"时如实说明该币当前无活跃异动，禁止用其他段补位。
6. 多空比是**账户占比**：>0.5 偏多、<0.5 偏空；top_accounts（大户）与 global_accounts（散户）方向相反是重大信号，必须点出。
7. 资金费率：正 = 多头付空头。**多空比偏多 + 费率高位 = 杠杆拥挤，必须提示连环爆仓（squeeze）风险**；反之亦然。
8. 恐惧贪婪：≤25 极度恐惧 / 25-45 恐惧 / 45-55 中性 / 55-75 贪婪 / ≥75 极度贪婪。仅作情绪背景，不推翻价格结论。
9. 脏数据保护：任何涨跌幅绝对值 >50% 视为坏数据，按缺失处理，绝不复述（单根 K 线涨幅是逐日口径，可放宽到 >20% 视为异常）。
10. 这是加密货币，不提股票概念（ticker、板块、财报、交易时段）。
